### 🎨 设计师（设计系统审计）

- **核心判断**：这套系统**不是"没有设计系统"，而是"系统已经跑起来了但没被正式命名"**。`app.css` 里的 `:root` / `[data-theme=night]` 双主题、对比度实测过的灰阶与主色、按"离内容多远"分档的浮层——这些是很多团队花半年才踩出来的，完成度约 **85%**。
- **关键是三层分账**（这是这套系统最独特的东西，也是最容易在扩写时被抹平的）：
  - **承担对比度的令牌**：`--accent`（填充 6.54／文字 5.54）、`--ink/--ink-2/--ink-3`、语义色。这些值动一个字都要重跑对比度脚本。
  - **只承担光晕的令牌**：`--accent-tint / --accent-line / --accent-glow / --sel-bg`，刻意留在亮蓝 `#2f6bff` 上——否则极光的通透感就没了。
  - **两者不可互换**：把 `#2f6bff` 拿去当填充，白字掉到 4.50；把 `--accent` 拿去当光晕，光晕会发脏。这条区分必须写进规范，而不是只活在注释里。
- **四个真缺口**：① 无 spacing 刻度（15／14／16／18／20 混用）；② 无 z-index 分层（抽屉 70、弹层各写数值）；③ 标签三种长相（`.chip` / `.pill` / 分镜行内临时壳）；④ 字号表七档但行内散着 13.5／15.5。
- **两条硬约束不要破**：零构建链（规范要能贴在原生 CSS 上）、磨砂只给压在滚动内容上的层（卡片挂 blur 是白付 GPU）。
