## 口径

- **视频**：640×352×81，带 `--fast-spatial`，记「秒／镜」；
- **图像**：1024×1024，记「秒／张」；
- **配音**：1 分钟音频的生成秒数；
- **文本**：首 token 与完整回答的秒数（带 tools 调用时分开记）；
- 一律记**目标机型号、内存、运行时版本**，否则半年后没人知道这个数是在哪台机器上得的。

## 为什么单列一份

`production_ready` 要求「环境检查 ＋ 真实调用 ＋ 产物验收」三条件齐。
本机的绿灯不能替目标机签字，一条基准没跑就不能把那一档标成 ready。

这张表全为「—」时，`tools/make_release_baseline.py --check` 会打印
「六条目标机基准一条未跑」的告警——它不阻断提交（本机开发本来就跑不了），
但会把这件事一直摆在发布基线里，不会因为页面好看就被忘掉。

## 到机后待增功能与收口清单

> 2026-11-27 核对《发布基线》《模型中心使用说明书》《生产工作台使用说明书》及近期资产工作流规划汇总；M5 Ultra 96GB 到位后按优先级逐项落地并回填上方六档实测读数。

### 一、引擎与生成底座接入（P0）

- [ ] **ComfyUI 执行适配器落地**（当前模型中心第 16 家已接探测与桌面启动，唯独缺执行层）：支持 Workflow JSON 模板化提交、进度轮询、中断取消、产物验收与自动入库。
- [ ] **主力本地模型与 MLX 节点部署**：在 96GB 统一内存上部署生图主力（FLUX / Kontext / IP-Adapter / PuLID / ControlNet）与生视频主力（Wan I2V / LTX-2 / FastMetal 5B-QAD），并实测单作业峰值显存与吞吐。
- [ ] **本地高精度多模态视觉 / 文本模型**：在 Ollama 部署大尺寸量化版文本与视觉模型（如 Qwen3 大参数版、Qwen2.5-VL / Qwen3-VL 高精度版），提升本地角色抽卡、看图反推提示词与出镜一致性自动质检质量。

### 二、参考图与角色资产 AI 增强（P1）

- [ ] **参考图「✨ 一键优化」接入 AI 超分与 AI 扩图**（接在现有「修正比例」弹窗中，与纯前端智能补边 / 交互裁剪并列）：
  - **AI 动漫超分提清（Upscale）**：接入 `RealESRGAN_x4plus_anime_6B` / `4x-UltraSharp`，一键 2x/4x 救活标红（`< 512px`）或低于槽位推荐分辨率的参考图，锁定五官与服饰不变形。
  - **AI 智能扩图（Outpainting）**：接入 FLUX Fill / ComfyUI Outpaint 工作流，为带复杂背景的场景参考图自然延展补全目标比例（`16:9` / `3:4`）。
- [ ] **角色 4 格设定集 + 主角 6 情绪表情差分本地直出**：基于 ComfyUI 参考图锁定节点（IP-Adapter / Kontext），支持建档时本地一键高质量直出 4 个标准槽位（面部特写 / 正面定妆照 / 三视图 / 背面高清图）与 6 张独立 1:1 表情差分图。
- [ ] **特写镜头一致性定向注入**：打通分镜生图 / 生视频首帧的「面部特写 + 表情差分」定向注入，降低特写镜头五官与眼神光漂移；同步完成《发布基线》中「按形态生成图像候选与参考图注入实测」收口。

### 三、音频、字幕与整集生产阻塞项收口（对照《发布基线》§3）

- [ ] **音频三轨补齐与实测**：在 96GB 显存上验证本地配乐（盯 `mlx-audio` 上游补 `acestep` 或评估 `minimax_music3` 24GB+ 显存档）、安装并接线口型同步（Rhubarb）与音效生成链。
