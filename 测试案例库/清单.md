# 现有代码测试案例清单（v1.0 · 2026-11-05 · 代码 `e4ba3c6`）

这份清单只覆盖**当前代码已经承诺的行为**。执行方式：`tools/run_checklist.py`（进程内 ASGI + 临时库 + mock 适配器 + 现场调 `worker.run_once`），
